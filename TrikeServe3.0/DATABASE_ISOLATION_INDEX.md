at database level\n- Checked for every SELECT, INSERT, UPDATE, DELETE\n- Cannot be bypassed\n\n### restaurant_id Column\n- New column in orders table\n- Links order to specific restaurant\n- Enables restaurant-based authorization\n\n### Authorization Chain\n```\nBusiness User\n    ↓\nOwns Restaurant\n    ↓\nHas Orders\n    ↓\nOnly sees these orders (via RLS)\n```\n\n### EXISTS Subquery\n```sql\nEXISTS (\n  SELECT 1 FROM restaurants\n  WHERE restaurants.id = orders.restaurant_id\n  AND restaurants.business_user_id = auth.uid()\n)\n```\n- Checks if user owns the restaurant\n- If true: allow access\n- If false: deny access\n\n---\n\n## 🔒 Security Layers\n\n```\nLayer 4: Database RLS ← NEW (Most Important)\nLayer 3: API Authentication\nLayer 2: Application Logic\nLayer 1:
