Order has restaurant_id set\n2. That restaurant exists in database\n3. That restaurant's owner is the current logged-in user\n\n---\n\n## 📊 Security Stack\n\n### Layer 1: Client-Side (localStorage)\n✅ Orders separated by restaurantId  \n✅ Filtered before display  \n✅ business_id UUID NOT NULL REFERENCES users(id),\n  restaurant_id UUID REFERENCES restaurants(id),  ← NEW!\n  items JSONB NOT NULL,\n  total_amount DECIMAL(10, 2),\n  status VARCHAR(50),\n  delivery_address VARCHAR(255),\n  created_at TIMESTAMP,\n  updated_at TIMESTAMP\n);\n\nCREATE INDEX idx_orders_restaurant ON orders(restaurant_id);\n```\n\n### Relationships\n```\norders\n  ├─ customer_id → users.id (who ordered)\n  ├─ business_id → users.id (restaurant owner)\n  └─ restaurant_id → restaurants.id (which restaurant)\n\nrestaurants\n  └─ business_user_id → users.id (owner)\n```\n\n---\n\n## 🔑 RLS Policies Implemented\n\n### Policy 1: Customers View Own Orders\n```sql\nCREATE POLICY \"Customers can view their own orders\" ON orders\n  FOR SELECT USING (auth.uid()::text = customer_id::text);\n```\n\n### Policy 2: Business View Restaurant Orders (KEY POLICY)\n```sql\nCREATE POLICY \"Business users can view orders for their restaurant only\" ON orders\n  FOR SELECT USING (\n    EXISTS (\n      SELECT 1 FROM restaurants\n      WHERE restaurants.id = orders.restaurant_id\n      AND restaurants.business_user_id = auth.uid()::text\n    )\n  );\n```\n\n### Policy 3: Customers Create Orders\n```sql\nCREATE POLICY \"Customers can create orders\" ON orders\n  FOR INSERT WITH CHECK (auth.uid()::text = customer_id::text);\n```\n\n### Policy 4: Business Update Orders\n```sql\nCREATE POLICY \"Business users can update orders for their restaurant only\" ON orders\n  FOR UPDATE USING (\n    EXISTS (\n      SELECT 1 FROM restaurants\n      WHERE restaurants.id = orders.restaurant_id\n      AND restaurants.business_user_id = auth.uid()::text\n    )\n  )\n  WITH CHECK (\n    EXISTS (\n      SELECT 1 FROM restaurants\n      WHERE restaurants.id = orders.restaurant_id\n      AND restaurants.business_user_id = auth.uid()::text\n    )\n  );\n```\n\n### Policy 5: Customers Update Own Orders\n```sql\nCREATE POLICY \"Customers can update their own orders\" ON orders\n  FOR UPDATE USING (auth.uid()::text = customer_id::text)\n  WITH CHECK (auth.uid()::text = customer_id::text);\n```\n\n---\n\n## 📊 Authorization Matrix\n\n| Action | Customer |
